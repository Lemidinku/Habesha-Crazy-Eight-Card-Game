# @crazy8/client

The React + Vite frontend for Crazy Eights Online — a thin, reactive UI that mirrors whatever the
server's last broadcast said and never computes game rules itself. See the
[root README](../../README.md) for the full project overview, and
[`HOW_IT_WORKS.md`](../../HOW_IT_WORKS.md) §4 for how this app is structured.

Run `pnpm --filter client dev` (from the repo root, after `pnpm install`) to run this app alone.
